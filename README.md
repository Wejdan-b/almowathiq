# الموثّق الذكي (Al-Mowathiq)

**فريق أثر** · تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026 · مؤسسة باذل الأهلية

نظام يأخذ صورة أو لقطة شاشة لمحتوى إسلامي (حديث أو فتوى)، ويتحقق منها مقابل قاعدة معرفة موثّقة، ثم يعرض النتيجة مع المصدر والدليل.

> النظام ليس مفتيًا، ولا يصدر حكمًا شرعيًا من عنده. كل نتيجة مربوطة بسجل موجود في قاعدة المعرفة ومصدره، وإذا لم يجد تطابقًا موثوقًا يقول ذلك صراحة.

## ⚙️ كيف يعمل

```
صورة ← قراءة النص (Gemini Vision OCR)
     ← التصنيف (حديث / فتوى / غير ذلك)
     ← البحث الهجين RAG (لفظي + بالمعنى: Embeddings + FAISS)
     ← التحقق السياقي (Gemini + حمايات حسابية)
     ← النتيجة + المصدر
```

1. **قراءة النص:** نسخ حرفي للنص العربي من الصورة دون تصحيح أو إكمال، مع تجاهل أسماء الحسابات والعلامات المائية.
2. **التصنيف:** يحدد نوع المحتوى ليبحث في الملف المناسب، مع شبكة أمان تبحث في النوعين إذا لم يتضح النوع.
3. **البحث الهجين (RAG):** توحيد النص العربي (التشكيل، الهمزات، التاء المربوطة، الأرقام، ﷺ)، ثم بحث لفظي بمقاطع الحروف، وبحث بالمعنى بنموذج `gemini-embedding-2` وفهرس FAISS. يجد النص حتى لو تغيّرت كلماته.
4. **التحقق:** يقارن نص الصورة بالمصدر المسترجع فقط، ولا يستخدم أي معرفة خارجية. والنص الصحيح المعروض يُنسخ دائمًا من السجل نفسه.

## 🧾 الحالات

| الحالة | السبب | متى |
|---|---|---|
| ✅ موثّق | مطابق | النص مطابق للمصدر |
| ✅ موثّق | مختصر | حُذف جزء لا يغيّر الحكم (مثل ذكر من قال به) |
| ⚠️ يحتاج تصحيح | مقتطع | حُذف شرط أو استثناء أو كلمة من النص |
| ⚠️ يحتاج تصحيح | محرّف | تغيّرت كلمة أو قُلب الحكم ("لا يحرم" ← "يحرم") |
| ⚠️ يحتاج تصحيح | منسوب لغير قائله | راوٍ أو قائل أو كتاب أو عالم يخالف المصدر |
| ⚠️ يحتاج تصحيح | لا يصح | حديث منتشر حكم المصدر بعدم صحته، مع البديل الصحيح |
| ⚪ غير موثّق | — | لم نجده في المصادر، وهذا لا يعني أنه غير صحيح |

## 🛡️ الأمان العلمي

حكم النموذج لا يُعتمد وحده في الحالات الحساسة، بل تدعمه حمايات حسابية مستقلة:

- **لا اتهام بدون دليل:** لا يُحكم بالتحريف إلا مع تطابق حرفي ≥ 0.5 أو تشابه معنى ≥ 0.8، وبعد تأكيد أنه نفس النص.
- **كشف قلب الحكم:** مقارنة النفي وكلمات الحكم (يجوز، يحرم، يجب، يسن...) بين الصورة والمصدر.
- **مقارنة كلمة بكلمة:** تحدد الكلمات المحذوفة والمضافة وتعرضها للمستخدم، مع تجاهل الفروق الإملائية الصغيرة.
- **التمييز بين الاختصار والاقتطاع:** حذف عبارات النسبة (مثل "باتفاق المذاهب الأربعة") لا يُعد اقتطاعًا.
- **كشف النسبة الخاطئة:** مقارنة الكتب المذكورة في الصورة بمصادر الحديث.
- **الموثوقية:** إعادة المحاولة عند ضغط الخدمة، ونماذج احتياطية تلقائية، وأي خطأ لا يُرجع "موثّق" أبدًا.
- **الخصوصية:** الصور تُعالج في الذاكرة فقط ولا تُحفظ.

## 📚 قاعدة المعرفة

| الملف | العدد | المصدر |
|---|---|---|
| `hadiths.json` | 15 حديثًا | الدرر السنية |
| `fake_hadiths.json` | 15 حديثًا منتشرًا لا يصح، مع بدائلها الصحيحة | الدرر السنية |
| `fatwas.json` | 20 فتوى، مع العلماء وكتبهم وصفحاتهم | الموسوعة الفقهية (الدرر السنية) وموقع الشيخ ابن باز |

كل سجل مربوط برابط صفحته في المصدر، ويمر على فاحص بيانات يرفض أي سجل ناقص المصدر. والنظام يتوسع بإضافة سجلات فقط، دون تعديل الكود.

## 💻 التشغيل محليًا

**السيرفر:**
```bash
cd almowathiq/backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env    # ثم ضع مفتاح Gemini داخل .env
.venv\Scripts\python -m uvicorn main:app --reload
```
مفتاح Gemini مجاني من: https://aistudio.google.com

**الواجهة:**
```bash
cd almowathiq/flutter_app
flutter pub get
flutter run -d chrome
```
(عنوان السيرفر في `lib/services/api.dart`)
